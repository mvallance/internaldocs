# Internal Documentation Repository

This repository houses our team's internal documentation: architecture notes, processes, runbooks, onboarding, and templates.

Primary goals:
- Provide a single, searchable source of truth for team operations.
- Standardize onboarding and process documentation.
- Maintain runbooks and incident response guidance.

How to use
1. Browse docs/ for content.
2. Propose documentation changes via PRs to this repo.
3. Use templates/ for meeting notes and decision logs.

Hosting
- This repo is set up to be served with MkDocs (mkdocs.yml included). Alternatively, publish with GitHub Pages or Docusaurus.

Structure overview
- docs/: Written documentation grouped by topic.
- .github/: Issue and PR templates to guide contributors.
- mkdocs.yml: Config for building a static docs site.

Maintainers
- Add team maintainers in docs/handbook/team_contacts.md.
